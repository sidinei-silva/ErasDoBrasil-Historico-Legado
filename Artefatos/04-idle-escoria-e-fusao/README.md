# Era 04 — Idle: A Escória e a fusão (mai–set/2026)

O spin-off idle inspirado no Albion Online ("Albion Idle" → "A Escória", codinome
"Outlander") e, a partir de 06/09/2026, o Eras do Brasil idle fundido (esqueleto da
Escória + mundo do Eras), em Go. A fase terminou em out/2026, quando o repositório Go foi
renomeado para `eras-do-brasil-idle` e o Eras recomeçou em TypeScript.

Os repositórios de código dessa fase continuam no GitHub (`escoria`, `escoria-arquivado`,
`eras-do-brasil-idle`). Aqui ficam os artefatos que vieram dos Projects do Claude:

|---|---|---|
| `claude-projects/projeto-outland/` | "Projeto Outland" — inclui `poc-albion-idle.md`, a especificação da PoC do tutorial "Albion Idle" | 27/05 → jun/2026 |
| `claude-projects/a-escoria-outlander/` | "A Escória (Outlander)" — instruções e `RECEITA.md` (como se trabalha no projeto) | 22/06 → set/2026 |
